Privacy Policy

Last updated: November 24, 2026

The TechFlash upload tool ("the app") is a private tool used only by the owner of the TechFlash YouTube channel to upload the channel's own videos and to read the channel's own statistics.

Data accessed

With the channel owner's permission, the app uses the YouTube Data API and the YouTube Analytics API to upload videos, set their titles, descriptions, captions and playlists, post comments on the channel's own videos, and read aggregated statistics (views, watch time, likes) of the channel.

Use and storage

Data is used only to publish and improve the channel's own videos. Access tokens and statistics are stored on the owner's private server and are never sold, shared or transferred to third parties. The app does not access data of any other YouTube user.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Contact the channel owner through the TechFlash YouTube channel.
